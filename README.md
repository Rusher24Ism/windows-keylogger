#_**Description:**_
A keylogger that can run on windows without getting detected by the anti-virus. It is coded in python. However, it is given the name and logo of the windows defender itself, which makes it harder to detect even checking in the task manager manually.

#_**Features:**_
Undetectable by windows defender
As the name itself is "Windows_Defender", along with the icon, it is hard to find it in task manager too

#_**Usage:**_
The main app is in the "dist" folder named "Windows_Defender.exe"
1.Press 'windows + r' to open run dialogue.
2.Type 'shell:startup' without the apostrophes and press enter.
3.Paste the "Windows_Defender.exe" file in there. (No need to paste the lib.txt as it will be run automatically)
4.The keylogger will run on startup automatically without any pop-up and detection. The keystrokes will be saved in automatically generated lib.txt file there.
